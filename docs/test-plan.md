## Affected Pages/Routes

- 세계 생성 플로우 — 랜덤 시드 시작 → 진행 표시 → 지도 등장 (§27.3 온보딩)
- 세계 목록/불러오기 — IndexedDB 저장 세계 선택, 버전 불일치 대화상자 (§28.6)

## Key Interactions to Verify

- 시간 진행(재생/배속/1틱/1년)과 일시 정지가 지도·차트에 즉시 반영되는지 — 메인 화면
- 중요 사건 발생 시 자동 일시 정지 + 사건 상세 패널 자동 오픈 (§9.5 majorEvent)
- 사건 상세에서 확률 계산 근거(기본 확률 × 보정치) 전체 표시 (§13.1)
- 도시 상세에서 인구 감소 원인 분해 표시 (§8.3 원장 집계)
- 사용자 개입(식량 지원 등) 적용 후 다음 틱부터 효과 반영
- 분기 생성 → 두 역사 비교 화면에서 수치 차이 표시 (§29)

## Edge Cases

- 폐허 도시 클릭 — 지도 흔적 표시 + 이력 열람, 생산/이주 대상 제외 (§8.2)
- 최대 배속에서 타임라인 아이템 폭주 — tickBatch 쓰로틀 초당 10회 (§9.5)
- LLM 키 미설정 상태에서 추천 요청 — 안내 메시지 (§27.2)
- LLM 실패 → 내장 템플릿 폴백 + 배너 표시 (§22)
- IndexedDB 용량 초과 — 오래된 스냅샷 정리 + 배너 (§28.5)
- 저장 세계 버전 불일치 — 로드 거부 대화상자 (§28.6)
- 빈 상태: 사건 0건 타임라인, 분기 1개뿐 비교 화면 (§27.2)

## Critical Paths

- 시드 → 월드젠(품질 재생성 포함) → 지도 표시 → 시간 진행 → 사건 발생 → 자동 정지 → 원인 확인 → 개입 → 관찰 재개 (핵심 루프, E2E로 전 구간)
- 스냅샷 저장 → 브라우저 재시작 → 로드(지도 재생성) → 재실행 해시 동일 (결정론 E2E)
- LLM 추천 요청 → 후보 표시 → 수동 승인 → 템플릿 등록 → 확률 평가 참여 → 재실행 시 저장 결과 재사용 (LLM 전체 경로)
